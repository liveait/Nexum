# RFC

RFC（Request for Comments）用于记录需要公开讨论的重大设计变更。

RFCs (Request for Comments) document major design changes that require public discussion.

<a id="scope"></a>
<a id="适用范围"></a>
## 适用范围 / Scope

以下变更应使用 RFC / Use an RFC for:

- Core 架构变化 / Core architecture changes
- Protocol 变化 / Protocol changes
- 公共 API 变化 / Public API changes
- 数据模型变化 / Data model changes
- 插件权限模型变化 / Plugin permission model changes
- Breaking Change / Breaking changes

<a id="suggested-structure"></a>
<a id="建议结构"></a>
## 建议结构 / Suggested Structure

通常包括摘要、动机、设计、替代方案、兼容性、安全性、实施计划和未解决问题。可沿用以下双语模板，标题与示例只维护一份。

An RFC normally includes Summary, Motivation, Design, Alternatives, Compatibility, Security, Implementation Plan, and Open Questions. Use the following shared bilingual outline.

```markdown
# RFC: <标题 / Title>

## 摘要 / Summary

## 动机 / Motivation

## 设计 / Design

## 替代方案 / Alternatives

## 兼容性 / Compatibility

## 安全性 / Security

## 实施计划 / Implementation Plan

## 未解决问题 / Open Questions
```

RFC 的目标是让重要技术决策具有公开、可追踪的上下文。

The goal is to give important technical decisions public and traceable context.
