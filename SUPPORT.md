# 获取帮助 / Support

一般问题请优先 / For general questions:

1. 搜索已有 Issue 和文档。<br>
   Search existing Issues and documentation.
2. 适用时创建新的 Issue，并提供完整复现信息。<br>
   Open an Issue with complete reproduction information when appropriate.
3. 对设计和功能方向提出建议时，使用 Discussion（如果仓库已启用）。<br>
   Use Discussions for design and feature-direction questions when enabled.

提交问题时，请尽量说明 / When reporting a problem, include:

- 操作系统与版本 / Operating system and version
- Nexum 版本或 commit / Nexum version or commit
- 使用的组件 / Relevant component
- 复现步骤 / Reproduction steps
- 实际结果 / Actual result
- 预期结果 / Expected result
- 相关日志或错误信息 / Relevant logs or error information
